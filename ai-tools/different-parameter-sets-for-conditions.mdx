Shipping Customizations offer **three parameter sets**. Each set exposes a different list of condition attributes, and a rule may use attributes from **only one set**.

<Warning>
  You cannot mix sets within a single rule. If the two attributes you need live in different sets, you need two rules — or a different approach.
</Warning>

## Switching sets

On the customization editor, the **Conditions** card has a **Switch to parameter set 2 / 3** link in its top-right corner. Clicking it cycles through the sets.

<Note>
  Switching sets resets the conditions on the rule, because the attribute you had selected may not exist in the new set. Decide which set you need before building out a long condition list.
</Note>

## What's in each set

### Set 1 — the default

| Group | Attributes |
| --- | --- |
| **Cart** | Cart Subtotal, Cart Quantity, Cart Weight |
| **Product** | Product Tag, Product Title, Product Type, Product Weight, Product Vendor, Variant Title, Line Item Property, Product Price, Product Collection |
| **Customer** | Customer Tag, Customer Logged In, Customer Company, Customer First Name |
| **Shipping** | Zipcode / Postcode, Country Code, Address Line 1, Address is a PO Box, Address is not a PO Box, Shipping Method Name, Shipping Rate |
| **Other** | Always, Number Of Vendors |

### Set 2 — SKUs, subscriptions, and customer metafields

| Group | Attributes |
| --- | --- |
| **Cart** | Cart Attribute |
| **Product** | SKU, Product Tag, Variant Metafield, Is subscription product |
| **Customer** | Customer Tag, Customer Metafield, Company Metafield, Customer First Name |
| **Shipping** | Province / State Code, Country Code, Address Line 1, Address is a PO Box, Address is not a PO Box |

Reach for set 2 when you need to match on **SKU**, on a **customer or company metafield**, on a **cart attribute**, or on whether the item is a **subscription**.

### Set 3 — product metafields and B2B locations

| Group | Attributes |
| --- | --- |
| **Cart** | Cart Subtotal, Cart Weight |
| **Product** | Product Metafield, Product Collection |
| **Customer** | Company Location Metafield, Customer First Name |
| **Shipping** | Zipcode / Postcode, Country Code |
| **Other** | Number Of Product Metafield Values |

Reach for set 3 when you need **Product Metafield** conditions or **B2B company location metafields**.
