The **Country Code** and **Province / State Code** conditions match on short codes, not on full names. Entering `United States` will never match — you need `US`.

Use the search below to find a code by country or province name.

<Tip>
  Country codes are separated by **semicolons** (`US;CA;GB`). Province codes are separated by **commas** (`CA,NY,TX`).
</Tip>

## Where these are used

**Country Code** appears in both [shipping rate](/customer-location-and-address) and [customization](/customer-location-and-address-1) conditions. Separate multiple values with **semicolons**:

```text
Condition 1: Country Code <> Equals <> US;CA;MX
```

**Province / State Code** appears in [shipping rate conditions](/customer-location-and-address), and in customization conditions under [parameter set 2](/ai-tools/different-parameter-sets-for-conditions). Separate multiple values with **commas**:

```text
Condition 1: Province / State Code <> Equals <> CA,NY,TX
```

<Warning>
  Province codes are only unique **within** a country. `CA` is California in the US and Canada as a country; `WA` is Washington in the US and Western Australia in Australia; `SA` is South Australia and also Saudi Arabia.

  Always pair a province condition with a country condition unless you ship to one country only.
</Warning>

```text
Rule must match: All conditions
Condition 1: Country Code <> Equals <> AU
Condition 2: Province / State Code <> Equals <> WA,NT
```

## Province coverage

Shopify only uses province codes for countries that have them. The lists above cover the countries ShipMagic merchants ask about most often.

If you need province codes for a country not listed here — India, Italy, Spain, Brazil, China, Mexico, Thailand, Indonesia and others all have them — check Shopify's own reference:

<Card title="Shopify countries and provinces" icon="arrow-up-right-from-square" href="https://matrixify.app/documentation/shopify-address-countries-and-provinces/">
  The full list of country and province codes Shopify accepts.
</Card>

<Note>
  Country codes follow **ISO 3166-1 alpha-2**. Province codes follow **ISO 3166-2**, with the subdivision prefix dropped for most countries — so California is `CA`, not `US-CA`. Japan is the notable exception, where the full `JP-13` form is used.
</Note>
