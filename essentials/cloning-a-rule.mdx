---
title: "Cloning a rule"
description: "Copy an existing rule's conditions and rates into a new one"
icon: "copy"
---

Cloning copies the conditions and rates from an existing rule into a new one, so you can build a variant of a rule you already trust without rebuilding it by hand.

## How to clone

<Steps>
  <Step title="Find the ID of the rule you want to copy">
    Every rule has a numeric ID. See [finding a rule ID](#finding-a-rule-id) below.
  </Step>
  <Step title="Start a new rule">
    Go to **Shipping Rates** and click **Add Rule**.
  </Step>
  <Step title="Open the clone dialog">
    Use the **Clone** action on the new rule page and enter the ID of the rule you want to copy.
  </Step>
  <Step title="Adjust and save">
    The form is populated with the source rule's conditions and rates. Change what you need, then set a **name** and a **priority** of its own and save.
  </Step>
</Steps>

<Warning>
  The clone arrives with the source rule's values, but **priority must be unique** — no two rules can share one. Give the clone its own priority before saving, or it won't save.
</Warning>

## Finding a rule ID

The rule ID is not shown on the rules list by default. ShipMagic keeps a short guide on locating it: [How to find the rule ID of a rule](https://shipmagic.tawk.help/article/how-to-find-the-rule-id-of-a-rule).

## What gets copied

Cloning brings across the parts of a rule that are laborious to recreate — its conditions and the rates attached to each zone. You still set the new rule's own identity: its name, its priority, and its status.

<Tip>
  Cloning is most useful when you have a rate table with many bands. Recreating a ten-band [ranged rate](/ranged-rates) by hand is tedious and easy to get wrong; cloning it and adjusting the prices is not.
</Tip>

## Common uses

**Seasonal variants.** Clone your standard rule, adjust the prices for a peak period, and keep the original inactive until you need it back.

**Regional variants.** Clone a rule that works well for one zone, then change the conditions to target another region with different pricing.

**Safe experiments.** Clone a live rule, modify the copy, and leave it **Inactive** until you've tested it. Then swap which one is active.

<Note>
  Cloning copies within a single store. To copy an entire setup between two stores, use [Cloning Full Setup from One Store to Another](/cloning-full-setup-from-one-store-to-another).
</Note>
